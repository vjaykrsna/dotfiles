# System Maintenance Plan

## Docker Backup Strategy

### Automated Docker Backup Script
```bash
#!/bin/bash
# docker-backup.sh - Automated Docker backup script

BACKUP_DIR="$HOME/docker-backups"
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_NAME="docker_backup_$DATE"

# Create backup directory
mkdir -p "$BACKUP_DIR"

echo "🗂️  Creating Docker backup: $BACKUP_NAME"

# Stop all running containers
echo "⏹️  Stopping running containers..."
docker stop $(docker ps -q) 2>/dev/null || true

# Create backup of all volumes
echo "💾 Backing up Docker volumes..."
docker run --rm -v /var/lib/docker/volumes:/volumes -v "$BACKUP_DIR:/backup" alpine tar czf "/backup/${BACKUP_NAME}_volumes.tar.gz" -C /volumes . 2>/dev/null || true

# Export all containers as images
echo "📦 Exporting container images..."
docker save $(docker images -q) -o "$BACKUP_DIR/${BACKUP_NAME}_images.tar" 2>/dev/null || true

# Backup Docker configuration
echo "⚙️  Backing up Docker configuration..."
sudo cp -r /etc/docker "$BACKUP_DIR/${BACKUP_NAME}_config" 2>/dev/null || true

# Restart containers
echo "▶️  Restarting containers..."
docker start $(docker ps -aq) 2>/dev/null || true

# Cleanup old backups (keep last 7)
echo "🧹 Cleaning up old backups..."
cd "$BACKUP_DIR" && ls -t docker_backup_* 2>/dev/null | tail -n +8 | xargs rm -f 2>/dev/null || true

echo "✅ Docker backup complete: $BACKUP_DIR/${BACKUP_NAME}"

# Show backup size
du -sh "$BACKUP_DIR"/* 2>/dev/null | head -3 || true
```

### Quick Docker Backup Alias
```bash
# Add to .zshrc aliases section
alias docker-backup='bash $HOME/docker-backup.sh'
alias docker-clean='docker system prune -af --volumes'
alias docker-stop-all='docker stop $(docker ps -q)'
alias docker-logs='docker logs -f --tail=100'
```

## System Update Commands

### Complete System Update Script
```bash
#!/bin/bash
# system-update.sh - Complete system update script

echo "🔄 Starting complete system update..."

# Update package lists
echo "📦 Updating package lists..."
sudo apt update

# Upgrade system packages
echo "⬆️  Upgrading system packages..."
sudo apt upgrade -y

# Upgrade distribution (if available)
echo "📈 Checking for distribution upgrades..."
sudo apt dist-upgrade -y

# Update Flatpak applications
echo "📱 Updating Flatpak applications..."
flatpak update -y

# Update Snap packages (if any)
echo "📦 Updating Snap packages..."
sudo snap refresh

# Update Rust toolchain
if command -v rustup &> /dev/null; then
    echo "🦀 Updating Rust toolchain..."
    rustup update
fi

# Update global npm packages
if command -v npm &> /dev/null; then
    echo "📦 Updating global npm packages..."
    npm update -g
fi

# Update pipx packages
if command -v pipx &> /dev/null; then
    echo "🐍 Updating pipx packages..."
    pipx upgrade-all
fi

# Update Cargo crates
if command -v cargo &> /dev/null; then
    echo "🦀 Updating Cargo crates..."
    cargo install-update -a
fi

# Clean up
echo "🧹 Cleaning up..."
sudo apt autoremove -y
sudo apt autoclean
sudo apt clean

echo "✅ System update complete!"
echo "🔄 Consider rebooting if kernel was updated"
```

### Quick Update Aliases
```bash
# Add to .zshrc aliases section
alias update-all='bash $HOME/system-update.sh'
alias update-system='sudo apt update && sudo apt upgrade -y && sudo apt autoremove -y'
alias update-flatpak='flatpak update -y'
alias update-rust='rustup update'
alias update-npm='npm update -g'
alias update-pipx='pipx upgrade-all'
```
